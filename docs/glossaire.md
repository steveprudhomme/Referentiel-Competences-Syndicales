# Les mots utiles
| Mot | Explication simple |
|---|---|
| AST | Décrire le travail avec les personnes qui le font |
| Pré-AST | Premier portrait, encore à vérifier |
| Corpus | Ensemble des textes ou données que nous étudions |
| Tâche | Travail à accomplir, comme préparer une réunion |
| Opération | Étape d'une tâche, comme préparer l'ordre du jour |
| Condition | Moyen, contrainte ou contexte pour faire le travail |
| Critère de réussite | Signe qui aide à dire que la tâche est bien réalisée |
| Compétence | Utiliser ses connaissances et ses habiletés dans une situation |
| Travail prescrit | Ce que les règles demandent |
| Travail réel | Ce que les personnes font dans leur contexte |
| Données primaires | Matériel recueilli directement, comme une entrevue |
| Analyse secondaire | Nouvelle lecture de données déjà recueillies |
| Verbatim | Transcription des paroles d'une personne |
| Traçabilité | Pouvoir retrouver d'où vient une information |
| Inférence | Déduction à vérifier, pas un fait confirmé |
| Référentiel | Ensemble organisé de compétences |
| Libération syndicale | Temps prévu pour exercer le mandat syndical |
