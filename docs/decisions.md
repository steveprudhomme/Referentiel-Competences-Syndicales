# Décisions et propositions
Les demandes de l'utilisateur et les recommandations de l'assistant sont distinguées. La présente mise en place suit la demande de poursuivre le projet; elle ne prouve pas une adoption officielle par un syndicat.

| Code | Élément | Origine et statut |
|---|---|---|
| D01 | Relier les compétences aux statuts locaux | Demande de l'utilisateur |
| D02 | Partir des recherches québécoises | Orientation discutée puis intégrée au protocole |
| D03 | Pré-AST sur publications avant les demandes de données | Demande de l'utilisateur; phase 1B |
| D04 | Reporter le croisement détaillé avec les statuts après la pré-AST | Recommandation méthodologique du dernier protocole |
| D05 | Pilote de vice-présidence au SSPHQ / SCFP 4250 et outil général | Proposition du protocole, terrain à organiser |
| D06 | Nom Referentiel-Competences-Syndicales | Choix matérialisé par le dépôt fourni |
| D07 | Français simple, Roadmap et commits thématiques | Demande explicite de l'utilisateur |
| D08 | Ne pas écraser les fichiers existants | Demande explicite; README initial conservé |
| D09 | Formation et développement, sans usage disciplinaire | Principe proposé dans la conversation |
| D10 | Licence | Aucun choix trouvé; à décider |
| D11 | Durées et effectifs | Estimations de planification; à ajuster |
Toute nouvelle décision doit préciser sa date, son auteur, sa raison et les fichiers concernés.
