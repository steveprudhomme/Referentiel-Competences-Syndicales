# Protéger les personnes et les documents
Ce dépôt est public. Il reçoit les méthodes, les modèles et les résultats autorisés à être diffusés.
Les entrevues brutes, les consentements signés, les clés reliant un code à une personne et les ententes privées restent dans un espace protégé hors du dépôt.
Un nom retiré ne suffit pas toujours : une fonction rare ou un récit précis peut permettre de reconnaître quelqu'un.
En cas de publication accidentelle, ne recopiez pas les renseignements dans un billet public. Prévenez le responsable par un canal privé. Retirer le fichier courant ne retire pas ses anciennes versions de l'historique Git.
Le fichier .gitignore est une aide, pas une protection complète.
