# Fiche de lecture
Copier ce modèle pour chaque activité repérée. Laisser « non décrit » quand le texte ne répond pas.

| Champ | À remplir |
|---|---|
| Code d'extraction | E001, E002… |
| Source et enquête d'origine | Code de bibliographie |
| Référence, version et date de lecture | Auteur, année, lien |
| Page imprimée / page PDF | Numéros exacts |
| Fonction et contexte | Présidence, vice-présidence, secteur, territoire, période |
| Origine du passage | Participant / auteur / équipe |
| Passage reformulé | Paraphrase fidèle; courte citation seulement si nécessaire |
| Tâche | Verbe et objet du travail |
| Opérations | Étapes réellement décrites |
| Conditions | Outils, autonomie, collaborations, temps, contraintes |
| Exigences et difficultés | Connaissances, habiletés, obstacles |
| Situation | Ordinaire / exceptionnelle |
| État documentaire | Explicite / inférée / à vérifier |
| Justification | Pourquoi ce code? Quelle limite? |
| Corroboration | Autres sources, indépendantes ou non |
| Validation terrain | Non consultée au départ |
| Question à poser | Ce qui manque |
| Analyste et date de relecture | Qui a vérifié? |

Le lien aux statuts est ajouté après la première lecture documentaire, en phase 4.
