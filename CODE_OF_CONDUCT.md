# Travailler avec respect
Écoutez les autres. Discutez des idées sans attaquer les personnes. Respectez les désaccords, les mandats élus et la diversité.
Ne publiez pas de noms de participants, de récits permettant de les reconnaître, de propos humiliants ou de documents privés.
Pour signaler un problème, utilisez un canal privé déjà convenu avec le responsable du projet. Si aucun canal n'est établi, demandez-en un sans raconter la situation en public.
Le responsable peut demander une correction ou retirer un contenu. Les décisions doivent être expliquées avec respect.
